## 03 / Research

### Selected Projects

#### 01 · PU-Boost
**Positive-Unlabeled Learning for Undiagnosed Hypertension Screening**

A two-stage reliable-sample reconstruction framework for learning from ambiguous clinical labels.

The method combines **Elastic Net global stratification**, **Random Forest refinement of uncertain samples**, uncertainty rejection, and final supervised learning on a reconstructed training population.

- 43,105-person analytic cohort
- 25,883 training samples
- 16,034 samples retained after reconstruction
- 81.72% sensitivity on the independent test set
- 41.1% fewer false negatives than standard XGBoost

**[Project Repository →](https://github.com/LionelWu11282562/A-Two-Stage-Probability-Stratified-Method-for-Ambiguous-Dataset-Optimization)**  
**[Full Project Page →](https://huanqiwu.com)**

#### 02 · Budesonide in IgA Nephropathy
**Real-World Evidence & Longitudinal Modeling**

A real-world longitudinal study evaluating enteric-release budesonide in patients with IgA nephropathy.

The analysis uses repeated clinical measurements and longitudinal mixed models to study changes in proteinuria and kidney-function trajectories.

- 38 patients
- 135 repeated observations
- Baseline, Month 3, Month 6, and Month 9 follow-up
- Longitudinal mixed-model analysis

**[Project Repository →](https://github.com/LionelWu11282562/Real-World-Budesonide-in-IgA-Nephropathy)**  
**[Full Project Page →](https://huanqiwu.com)**

#### 03 · cfMethylFormer
**Transformer Representation Learning for cfDNA Methylation**

A concept-stage computational genomics project exploring transformer-based representation learning for **cell-free DNA methylation**.

The framework extends methylation-aware read-level sequence representations toward **multi-read aggregation and sample-level prediction**.

`cfDNA` · `DNA Methylation` · `Transformer` · `Representation Learning` · `Computational Genomics`
